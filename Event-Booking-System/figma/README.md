# Figma UI board

`event-booking-system-ui.svg` is an editable SVG representation of the current Vue interface. It includes:

- Home / featured events
- Event discovery and filtering
- Seat selection and checkout summary
- Color, typography, spacing, and component-state tokens

## Import into Figma

1. Open a Figma design file.
2. Drag `event-booking-system-ui.svg` onto the canvas, or use **File → Place image**.
3. Right-click the imported artwork and choose **Ungroup** as needed to edit vector layers and text.

The board intentionally uses the values in `src/assets/main.css` (`#0b0b0c`, `#141416`, `#f3c64f`, `#9e1c4e`, and the Inter-style type scale). It is a design reference, not a native `.fig` binary; native Figma files are proprietary and require Figma itself or an authenticated Figma API/plugin environment to create.
